# NMR Figure Editor

JEOL Delta で処理した `.jdf` を読み込み、重ね書き・不純物マーカー・図形の書き込みをして、
Word / PowerPoint 用の図を作るブラウザアプリです。反応の経時変化を追う推移グラフも作れます。
データはパソコンの外に送信されません。

仕様と今後の予定は [docs/SPEC.md](docs/SPEC.md) にあります。

## 使う (いちばん簡単)

**https://sakyooooo.github.io/nmr-figure/**

ブラウザで開くだけです。インストールは要りません。研究室でも家でも、同じ URL で使えます。

- **測定データは外に出ません**。このアプリはブラウザの中だけで動き、外部に通信しません。
  データは各自の PC の中 (ブラウザの保存領域と、保存した `.jdf` / `.nmrfig` ファイル) だけです
  - コードの約束だけでなく、**ブラウザが外への通信を止めています** (CSP: Content-Security-Policy)。
    外のサイトへの送信・外の画像の読み込み・フォームの送信は、仮にコードが試みてもブラウザが拒否します
  - 確かめ方: F12 → Console で `fetch('https://example.com')` と打つと「Content Security Policy に違反」と出て止まります
- Chrome / Edge で開いてください (フォルダの読み込み・上書き保存・図のコピーに必要です)
- 初回は「データフォルダを選ぶ」で `.jdf` の入ったフォルダを選びます

### 使い方の説明・言語 (English)

- 初めて開いたときに、使い方の説明 (5 枚) が出ます。あとからはホーム画面の「使い方」、設定、操作を探す (Ctrl+K) から見直せます。
- 画面は日本語と英語に対応しています。ふだんはブラウザの言語に合わせ (日本語以外は英語)、説明の 1 枚目か設定の「Language / 言語」で切り替えられます。
- The app is available in English. It follows your browser language; switch it on the first page of the guide or in Settings → "Language / 言語".

### アプリとして入れる (`.nmrfig` をダブルクリックで開く)

Edge (または Chrome) にアプリとして入れると、スタートメニューから起動でき、保存した `.nmrfig` (2D の図など) をダブルクリックで開けます。
図入りの `.jdf` はこれまでどおり Delta で開きます (このソフトで開くときは、ホーム画面の「図」か、ドロップで)。

1. Edge で上の URL を開き、アドレスバーの右の「アプリを利用できます」のボタン (または「…」→「アプリ」→「このサイトをアプリとしてインストール」) を押します
2. 入れたあと、`.nmrfig` を右クリック →「プログラムから開く」→「NMR Figure Editor」→「常にこのアプリを使って開く」にします
   (初めて開くときは「ファイルを開くことを許可しますか」と聞かれるので、許可します)
3. アプリの窓が開いていれば、ダブルクリックした図はその窓で開きます (編集中の図が未保存なら、先に確認が出ます)

## 起動 (自分の PC で、中身を直しながら)

**ふだん使うとき**: フォルダの中の **`NMR図編集ソフトを起動.bat`** をダブルクリックします。
黒い窓が開いてブラウザにアプリが出ます (http://localhost:4173)。使い終わったら黒い窓を閉じます。

- よく使うなら、この .bat を右クリック →「送る」→「デスクトップ (ショートカットを作成)」でデスクトップから起動できます。
- 初回は「データフォルダを選ぶ」で `.jdf` の入ったフォルダを選びます。次からは自動で読み込みます
  (ブラウザを開き直したときは「フォルダを読み込む」を1回押します)。
- Chrome / Edge で開いてください (フォルダの読み込み・上書き保存・図のコピーに必要です)。

**中身を直しながら使うとき** (開発):

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。保存するたびに画面が更新されます。

**ほかのパソコンでも使いたいとき**: `npm run build` で `dist/` に static なファイルができます。
これを社内サーバーや GitHub Pages などの https に置けば、Node.js なしでブラウザだけで使えます。

## 使い方

### ホーム画面 (実験を選ぶ)

1. 最初に「データフォルダを選ぶ」で `.jdf` が入っているフォルダを選びます。次からは自動で読み込みます
   (ブラウザを開き直したときは「フォルダを読み込む」を1回押します)。新しく測定したら「更新」を押します。
   - 許可のダイアログに「毎回このサイトで許可する」があればチェックを入れると、次からは何も押さずに一覧が出ます。
   - ボタンが「**フォルダを選び直す**」になっているときは、ブラウザが拒否を覚えている状態です。
     このときは許可のダイアログが出ないので、ボタンを押してフォルダを選び直してください。
2. 実験は測定日ごとに、サンプル (Delta のタイトル) ごとにまとまって並びます。
   検索・核種 (¹H / ¹³C / ¹⁹F / ³¹P / 2D)・溶媒・タグで絞り込めます。
   「並び」で順番を変えられます。
   - **測定日**: 日ごとにまとまって並びます (初期値)。
   - **名前**: サンプル名の順 (A → Z)。日でまとめず、同じサンプルの測定が1つのカードにまとまります。
   - **編集順 (保存した日時)**: Delta で処理して保存した日時の順。最近さわったサンプルが上に来ます。

   隣のボタン (↓ / ↑) で降順と昇順が入れ替わります。選んだ並びは次に開いたときも続きます。
3. 実験をクリックすると、右にスペクトルのプレビューと測定条件が出ます。ダブルクリック (タッチ画面ではダブルタップ) で開きます。
   チェックを付けて「新しい図で開く」と、まとめて開いて重ね書きになります (測定順)。
   Delta の生データ (`〜-1-1.jdf`) と処理して保存した版 (`-1-2`, `-1-3` …) は1つの測定にまとまり、最新の処理版が開きます。
   このソフトで編集して保存した図も、その測定の版にまとまります (札に「編集」「2 版」と出て、開くと編集した図が開きます)。
   ほかの版は右の「ファイル」で選べます。生データしかない測定には「FID」と出ます。開くと、このアプリで FT・位相補正します。
4. 右側で、サンプルごとにスキーム・メモ・タグを付けられます。同じサンプル名の測定すべてに共通で、このブラウザの中に保存されます。
   - **「描く」** を押すと、このアプリの中で構造式や反応式を描けます (Ketcher)。原子・結合・環・反応矢印が使えて、
     描いたものは画像として保存され、あとから「描き直す」で続きを直せます。計算もすべてパソコンの中だけで行います。
   - ChemDraw などからコピーした画像を Ctrl+V で貼る / 画像をドロップする、これまでの方法も使えます。
5. 編集画面の「← ホーム」で戻れます。編集中の図はそのまま残り、「編集中の図に戻る」「編集中の図に追加」ができます。

2D (COSY・HMBC・HSQC など) も開けます。生データのまま、このアプリで 2次元の FT をします。

### 編集画面

1. `.jdf` を開きます (ホーム画面から、またはドロップ)。Delta で処理して保存したものも、未処理の生データ (FID) も開けます。複数まとめて入れると縦に並びます。
2. 左の「スペクトル」で名前 (例: `0 h`, `SM`)、色、倍率、溶媒を設定します。溶媒はファイルから自動で判定します。
3. 右の「不純物の候補」で、付けたいものにチェックを入れると、マーカーと凡例が付きます。
   「マーカー・凡例」には色違いのマーカーが 6 つ並んでいます。色を選んでピークをクリックすると印が付きます。
   名前を入れた色だけが凡例に出ます (空のままなら凡例には出ません)。
   右の「図に入れるもの」で、図の下のタイトル (例: ¹⁹F NMR (376 MHz, THF-d₈))・軸の説明・外枠 (図全体を囲む線)・枠 (グラフの囲み)・縦軸を入れるか選べます。
   タイトルは「自動」を外すと自由に書けます (核種の違うスペクトルを並べたときなど)。
4. ツールバーで図形 (楕円・四角・矢印・線・テキスト) を描き、「ピーク値」ツールでピークをクリックすると値が付きます。
5. 「図をコピー」でクリップボードへ送れます。Word / PowerPoint にはベクター (SVG) の図として貼られるので、拡大しても印刷しても荒くなりません。
6. 「保存」で、図の入った `.jdf` に保存します (下の「Delta の形式で保存」)。スペクトルデータも含むので、元の `.jdf` を動かしても開けます。

### Delta の形式で保存 (図入りの .jdf)

- 保存したファイルは Delta と同じ `.jdf` です。**フォルダでダブルクリックすると Delta が開き**、スペクトルとピーク値・積分が出ます。
- **このソフトで開くと、図がそのまま戻ります** (重ねたスペクトル・マーカー・図形・文字・構造式・図の設定まで)。
  ホーム画面では、図入りの `.jdf` は元の測定の「編集した版」として、その測定の札にまとまります (行は増えません)。
- Delta で見えるのは、図の一番下に描いているスペクトル (土台) だけです。重ねたほかのスペクトルは、このソフトで開いたときに出ます。
- このソフトで FID から処理したスペクトルは、Delta が処理したファイルと同じ形 (処理済みのスペクトル) にして保存します。
- 図の中身は Delta のパラメーター `nmrfig_info` / `nmrfig_summary` / `nmrfig_data_001…` に入っています。
  Delta のパラメーターの一覧に見えますが、消さないでください (消すと、このソフトで開いたときに図が戻らなくなります)。
- 保存したあとは、土台のスペクトルのピーク値・積分はその図の `.jdf` と同期します (Delta で変えて保存すると、図に入ります)。
  FID から処理したスペクトルも同じです。このソフトで位相などを変えると `.jdf` のスペクトルも書き直し、
  Delta で処理し直して保存すると、Delta のスペクトルに切り替わります (このソフトでの位相補正は使わなくなります)。
- 2D の図と、文献のスペクトルだけの図は `.jdf` にできないので、これまでどおり `.nmrfig` に保存します。

### 保存のしくみ

- **作業中の図は、何もしなくてもブラウザに自動保存されます。** 画面を閉じても、次に開いたときにホーム画面の
  「編集中の図に戻る →」から続きを編集できます。画面の下に「自動保存 11:38」のように時刻が出ます。
- **ファイルに保存するとき**は「保存」を押します。1回目だけ保存する場所を聞かれ、
  2回目からはボタンが「**上書き保存**」に変わり、同じファイルに黙って上書きします (`Ctrl+S` でも同じ)。
- 保存先はブラウザを閉じても覚えています。開き直して最初に上書き保存するときだけ、
  ブラウザが「ファイルへの書き込みを許可しますか」と聞くので、許可してください。
- 別のファイルにしたいときは「別名で保存」を押します。
- 画面の下に、いまのファイル名と「未保存の変更あり / 保存済み」が出ます。
- ドラッグ&ドロップで開いた図入りの `.jdf` / `.nmrfig` も、そのまま上書き保存できます。
  前に `.nmrfig` で保存した図は、次に保存するとき `.jdf` の保存先を聞きます。

自動保存に残るのは **いま開いている図だけ** です。別の実験を開くと前の図は消えるので、
残しておきたい図はファイルに保存してください (未保存のまま別の図を開こうとすると確認が出ます)。

### 未処理の測定 (FID) を開く

Delta で処理していない生データ (`〜-1-1.jdf`) は、開くときにこのアプリで次の処理をします。

1. FT (指数関数の窓: ¹H 0.2 Hz / ³¹P 2 Hz / ほか 1 Hz、ゼロ詰め 2 倍)
2. 位相補正 (装置の遅れを補正したうえで自動)
3. ベースライン補正
4. 溶媒ピークで基準合わせ (設定の研究室の基準値。C₆D₆ の ¹H なら 7.15)

右の「FID の処理 (位相補正)」で、あとから直せます。

- 位相がずれていたら「位相を自動で合わせる」か、0次・1次のスライダーで合わせます。1次位相は「中心」のピークでは効かないので、
  まず中心 (初めは一番大きいピーク) の形を 0次で合わせ、遠くのピークの形を 1次で合わせます。
- 線幅 (LB) を大きくするとノイズが減り、線は太くなります。
- 保存した `.nmrfig` には生データも入るので、開き直しても調整できます。

### 2D (COSY・HMBC など)

一覧で「2D」と出ている測定を開くと、等高線の図になります。Delta で処理していない生データのまま、
2次元の FT (サインベル窓 → ゼロ詰め → FT → 絶対値) をします。COSY や HMBC は絶対値で見るのが普通なので、位相補正は要りません。

- **動かす**: ドラッグで移動、ホイールで拡大縮小、ダブルクリックで全体表示。範囲を拡大ツール (`Z`) で四角く囲んでも拡大できます。
  左下に、カーソルの位置の F2 / F1 の ppm が出ます。
- **等高線**: 右の「等高線」で、下限 (一番低い線の高さ)・本数・1本ごとの倍率・色・線幅を変えられます。
  下限の初期値は雑音から自動で決めます。弱い交差ピークを見たいときは「↓ 下げる」を押します。
- **上と右の投影**: 表示している範囲の最大値を線にしたものです。チェックを外すと消えます。
- **対角線**: 同じ核種どうし (COSY など) のときに点線で出ます。
- 図は 1D と同じく「図をコピー」「SVG」「PNG」で書き出せます。`.nmrfig` に保存すると、生データごと残ります。

2D と 1D は同じ図に混ぜられません (2D を開くと 1D の図は閉じます)。図形・ピーク値ラベル・積分は 2D では使えません。

### ピークの高さを変える

小さいピークを見たいときは、全体を引き上げます。大きいピーク (溶媒など) は枠の上で切れます。

- ツールバーの **高さツール** (山に ↕ のアイコン、`H`) を選び、図の上を **上下にドラッグ** します。全部のスペクトルが一緒に高くなります。
  Shift を押しながらだと、ドラッグしたスペクトルだけが変わります。
- ツールバーの **↑ ↓ ボタン** でも、1回押すごとに 1.5 倍ずつ高く/低くなります。
- 高さツールのときは、ホイールだけで高さが変わります (ほかのツールでは Shift+ホイール)。
- 数値で変えるときは、左の「倍率」(スペクトルごと) と「縦倍率」(全体) を使います。「縦を自動」で表示範囲の最大ピークに合わせ直せます。
- 選択ツールで背景を上下にドラッグしても、そのスペクトルの高さが変わります (左右は表示範囲の移動)。

### 積分 (自動積分)

1. 右の「**積分**」で「**自動で積分**」を押すと、信号をまとめて積分します。
   - 溶媒の残存ピークと、不純物マーカーを付けたピークは除きます。
   - 「高さ ○%以上」で拾う下限を決めます (既定 3%。小さい信号も入れたいときは下げます)。
   - 「表示範囲だけ」を入れると、今見えている範囲の信号だけを積分します。
   - すでにある積分と重なるところには作らないので、手で引いた積分は消えません。何度押しても増えるだけです。
2. 手で引くときは積分ツール (I) で、ピークを左右にドラッグします。続けて何本でも引けます。
3. 値は、基準がなければ最初に引いた積分が 1.00 です。右の「積分」で値を書き換えると (例: 12)、その積分を基準にほかがそろいます。
4. 引いた積分をクリックすると選べます。両端の四角をドラッグすると範囲を変えられ、Delete で消せます。表の × でも消せます。
5. 「積分の見た目」で、積分曲線の表示、値の位置 (曲線の上 = Delta 風 / 軸の下にかぎ括弧)、小数の桁、曲線の高さを変えられます。
6. 「**両端の直線を引く**」(初期値: 入) は、範囲の両端を結ぶ直線を引いてから足す Delta と同じ出し方です。
   直線は Delta と同じく「両端それぞれ 11 点の平均」を結びます。研究室の .jdf の積分 406 件で、Delta の値と計算の誤差まで一致しました。
   外すと単純な強度の和になります。

### ピーク値 (ピークピックアップ)

1. 右の「**ピーク値**」で「**自動で拾う**」を押すと、ピークにまとめて値が付きます。
   - 「高さ ○%以上」が下限です (既定 5%。一番高いピークを 100% とした割合)。ノイズは自動で除きます。
   - 「表示範囲だけ」を外すと、見えていない範囲のピークも拾います。
   - すでに付いているピークは重ねて付けません。
2. 1 本ずつ付け外しするときは「手で付ける」(ピーク値ツール P) でピークをクリックします。
3. 表には ppm と高さ (一番高いピークを 100 とした %) が並びます。行をクリックすると図の上で選ばれ、× で 1 本だけ消せます。
4. 「**表をコピー**」で Excel に貼れるタブ区切り、「**値だけコピー**」で `7.262, 3.451, …` の形でコピーします。
5. 「ピーク値の見た目」で小数の桁と位置 (軸の下 / ピークの上) を変えられます。

Delta で処理したファイル (`-1-2` など) に付いているピーク値・積分は、**開いたときに自動で入ります** (下の「Delta との同期」)。
積分は Delta のベースライン (手で直したものも) と「この積分を 4 にする」のようなそろえ方も引き継ぐので、**Delta の画面と同じ数字**になります。
データフォルダの外のファイルなど、同期していないときは「Delta のピーク値を取り込む」「Delta の積分を取り込む」で入れられます。

### 作った図をホーム画面に残す

図を「保存」すると、その図に入っている測定の**サンプルのカードに並びます**（測定のチップの横に、青い「図」のチップとして出ます）。
クリックすると、その図をそのまま開き直せます。

- 違うサンプルの測定を混ぜた図は、**使ったサンプルすべて**のカードに出ます
- 保存先はブラウザの中です (メモやスキームと同じ場所)。`.nmrfig` ファイルとは別に、開き直す用の控えが残ると考えてください
- いらなくなったら、チップの `×` で消せます (測定データや `.nmrfig` は消えません)
- 同じ図を何度保存しても、チップは 1 つのまま新しくなります

### Delta との同期 (自動で相互編集)

Delta で処理済みの `.jdf` (`-1-2` など) を開くと、**ピーク値と積分が Delta と自動で行き来します**。ボタンを押す必要はありません。

- **このソフト → Delta**: ピーク値・積分を変えると、少し待ってから (約 1.5 秒) 同じ `.jdf` に書き込みます (上書き)。
  積分のそろえ方 (「この積分を 9 にする」) も書くので、Delta の画面にも同じ数字が出ます
- **Delta → このソフト**: Delta で保存すると、数秒以内 (このソフトの画面に戻ったときはすぐ) に図へ入ります。
  Delta でスペクトルを処理し直して (位相など) 保存したときは、スペクトルも読み直します
- **両方で変えたとき**は、あとから変えた方を使います。使わなかった方も「記録」に残ります
- **Delta で開いたままの画面は、外から書き換えられません**。このソフトの変更は、Delta でファイルを開き直すと見えます
- 初めて書き込むとき、ブラウザが「データフォルダへの書き込みを許可しますか」と聞きます。許可してください
  (右の「Delta との同期・記録」に「書き込みを許可する」ボタンも出ます)
- Delta で付けた文字などの注釈 (ピーク値・積分以外) は、そのまま残します
- この機能より前に作った図を開いて、図と `.jdf` の中身が違うときは、どちらに合わせるかを一度だけ聞きます
- 対象外: FID をこのソフトで処理したスペクトル、文献から作ったスペクトル (Delta のファイルがないため)

図にピーク値や積分を**出したくないとき**は、右の「図に入れるもの」の「ピーク値」「積分」を外してください。
消すと Delta のファイルからも消えるので、図から外すだけならこちらを使います。

### 編集記録 (好きなときに残して、その時点に戻す)

右の「**編集記録**」(Delta と同期しているときは「Delta との同期・記録」) で、今のピーク値・積分を残せます。

1. 残したいときに「**記録を付ける**」を押します。**メモは任意**です (空のままでも残せます。入れるときは入力して Enter でも可)
2. 一覧の行を押すと、その時点の積分の値とピーク値が見られます。メモはあとから書き足し・書き直しできます
3. 「**この時点に戻す**」で、その時点の中身に戻します。Delta と同期していれば Delta のファイルも戻ります
   (Delta と同じ中身のときに付けた記録は、Delta が書いたとおりに、文字などの注釈も含めて戻ります)
4. 「**別の .jdf に書き出す**」で、その時点の中身を別のファイルにできます (元のファイルは変えません)。いらない記録は「記録を消す」で消せます

FID をこのソフトで処理したスペクトルなど、Delta と同期しないものにも記録は付けられます (戻すのは図だけです)。

**自動の控え**: Delta もこのソフトも同じファイルに上書きするので、上書きされた中身を取り戻せるよう、同期のたびに自動でも残しています。
ふだんは畳んであり (「自動の控え (n)」を開くと見られます)、ファイルごとに新しい 100 件まで残します。
ここから「このソフトで書き込む前のファイルに戻す」(初めて書き込む前のファイル、スペクトルも注釈も) もできます。

記録はこのブラウザの中に置きます (消されないよう、ブラウザに保管をお願いしています)。自分で付けた記録は自動では消えません。

### SI 用テキスト

右の「SI 用テキスト」で、論文の Supporting Information に貼る文を作ります。

```
¹H NMR (400 MHz, C₆D₆) δ 3.67 (t, J = 5.2 Hz, 18H), 3.58 (d, J = 10.4 Hz, 9H), 1.33 (d, J = 6.6 Hz, 12H).
³¹P{¹H} NMR (162 MHz, C₆D₆) δ 129.6, …
```

1. ¹H は「信号を自動で積分」を押す (または積分ツールで範囲を引く) と、範囲ごとに多重度 (s, d, t, q, dd, dt, sept …) と J を自動で読みます。
   重なって読めない信号は範囲付きの m になります。溶媒と、不純物マーカーを付けたピークは自動では拾いません。
2. 積分パネルで基準の値 (例: iPr の CH₃ = 12) を入れると、H の数がそろいます。
3. 違うところは表で直します (多重度・J・H 数・帰属)。直した多重度はオレンジ色になります。帰属は `OCH_{3}` のように書けます。
4. ¹³C などは、積分があれば同じように、なければピーク値ラベル、それもなければ自動で拾ったピークを並べます。
5. 「Word 用にコピー」で、上付き・下付き・斜体の *J* を残したまま貼れます。「テキストでコピー」は ¹H, C₆D₆ などを Unicode の文字で書きます。
   表示中のスペクトルすべてが ¹H → ¹³C → ¹⁹F → ³¹P の順に並びます。

### 図に構造式を置く

ツールバーの **六角形のボタン** を押すと構造式エディタが開き、描いて保存すると図の中に入ります。

- 置いた構造式は **ドラッグで移動**、**右下の角で大きさ変更**。右のパネルでも大きさを数値で決められます。
- **ダブルクリック** すると描き直せます。Delete で消せます。
- 位置は図の中で固定です (表示範囲を変えても動きません)。
- 図の上で **Ctrl+V** すると、ChemDraw などからコピーした画像をそのまま置けます。
  ChemDraw で「Copy As → SMILES」した文字を貼ると、構造式エディタが開いてその構造から描き直せます。
- **Word / PowerPoint での編集**: このアプリで描いた構造式はベクター (SVG) のまま図に入るので、
  貼り付けてから右クリック →「図形に変換」すると線や文字を編集できます。
  貼り付けた画像 (PNG) は編集できません。編集したいときは、構造式ボタンから描き直してください。

### ChemDraw の構造式を使う (Word の上で ChemDraw で直せる図)

ChemDraw で描いた構造式 (過去に描いたものも) をそのまま図に置き、帰属の印を付けて Word に貼れます。
Word に貼ったあとも、ダブルクリックすると ChemDraw が開いて構造式を直せます。

0. 初めてのときだけ、このアプリのフォルダの **tools\chemdraw-link\ChemDraw連携を入れる.bat** をダブルクリックして、
   NMR の保存先 (ホーム画面で開くフォルダ) を選びます (管理者の権限は要りません。外すときは ChemDraw連携を外す.bat)。
1. 下の道具箱の **六角形のボタン** (構造式) を押し、「ChemDraw で描く」を選びます (初めてのときだけ聞かれます。設定で変えられます)。
   すぐ ChemDraw が開きます (開いている ChemDraw があれば、その中に開きます)。描いた内容は、**保存しなくても** そのまま図に入ります。
   - 初めてのときは、Edge が「このアプリを開きますか」と聞くので許可してください。
   - 構造式は NMR の保存先の中の「ChemDraw」フォルダに置かれます。
   - 過去の構造式は、ChemDraw で **Edit > Copy As > CDXML Text** でコピーして図の上で **Ctrl+V** しても置けます
     (.cdxml を図にドロップしても置けます。ChemDraw でふつうに Ctrl+C したものは、ブラウザでは読めません)。
2. 文字ツールで構造式の上をクリックして、帰属の印 (a, b, 1' など) を置きます。構造式の上に置いた文字は構造式に付いて、一緒に動きます。
3. **書き出し > ChemDraw で開く** で .cdxml を保存し、開くと ChemDraw が起動します。
4. ChemDraw で **Ctrl+A → Ctrl+C** して、Word に **Ctrl+V**。

- スペクトルは今までどおりの見た目 (線のまま) で入ります。構造式と印は ChemDraw のデータなので、Word でダブルクリックして直せます。
- 図の中の構造式を直すときは、ダブルクリック (または「ChemDraw で直す」) で ChemDraw が開きます。直すとそのまま図も変わります
  (位置と、上に置いた帰属の印はそのまま)。閉じるときに保存を聞かれることもありません。
- Word に貼った図をダブルクリックすると、開いている ChemDraw の窓の中に図が開きます (新しい窓は出ません)。ChemDraw が後ろに隠れていたら、タスクバーから前に出してください。

### 文献 (SI) のデータと比べる

論文の SI に書かれた NMR データから、比較用のスペクトルを作って重ねられます。生データがない文献と見比べるときに使います。

1. ツールバーの「**文献から**」を押します。
2. SI の文をそのまま貼り付けます (例: `1H NMR (400 MHz, CDCl3) δ 7.30 (d, J = 8.0 Hz, 2H), 3.45 (q, J = 7.0 Hz, 2H), …`)。
   δ・多重度 (s, d, t, q, dd, sept, m …)・J・H 数を読み取り、その位置に線を立てます。範囲で書かれた m は、その範囲に広がる山にします。
3. **引用元を入れます (必須)**。入れないと追加できません。
4. できたスペクトルは**紫色**で、名前が「文献値から作図 (Tsurugi 2024)」のようになります。
   論文の実測スペクトルではなく、書かれた値から作った線だと分かるようにするためです。
   名前は書き換えられますが、図の下の「文献値から作図: (引用元)」の行は消せません。

引用元は、雑に貼っても**自動で形を整えます**。論文サイトの「Cite」、PDF からの貼り付け (文献番号・改行・行末のハイフン・表題つき)、
PubMed 式 (`Smith JA, Jones B. … J Am Chem Soc. 2024;146(3):1234-1240.`)、Wiley 式 (`H. Tsurugi, K. Mashima, Angew. Chem. Int. Ed. …`)、
DOI や `https://doi.org/…` だけ、のどれでも次の形になります。

> Tsurugi, H. et al. *J. Am. Chem. Soc.* **2024**, *146*, 1234.

- ACS の書き方に合わせて、**誌名と巻は斜体、年は太字**、頁は**最初の頁だけ**書いて「.」で閉じます。DOI は出しません。
- 著者は「筆頭著者 + et al.」に直します。`Tsurugi, H.; …` も `H. Tsurugi, …` も `Ka Wing Chan; …` (綴りのまま) も読めます。責任著者の `*` は外します。
- 誌名はよく使う略号 (`Journal of the American Chemical Society` → `J. Am. Chem. Soc.`) に直します。`of` `the` が抜けていても引けます。表題と号は落とします。
- **整えるのは貼り付けたときだけ**です。手で直した文はそのまま図に出ます。直したあとにもう一度整えたいときは「形を整える」を押します。
- 図に追加したあとでも、左の「スペクトル」で直せます。
  - **引用元**はその場で書き換えられます (「整える」ボタンで形を整え直せます)
  - 「**文献データを直す**」で、SI の文・線幅・文献の図を入れ直して**作り直せます**。
    レイヤーの色・並び・自分で付けた名前はそのまま残ります
- 形を読み取れなかったときは、**消さずにそのまま**図に出します (改行と余分な空白だけ直します)。
- 整えた直後に「元に戻す」が出ます。手で書き直すこともできます。

引用元は**必ず図に出ます**。図の下に、タイトルに続けて「文献値から作図: 全文」が入ります。消すことはできません。

線幅は変えられます (初期値 ¹H 1.2 Hz、ほか 3 Hz)。実測ではなく「書かれた値から作った線」なので、
ピーク位置と積分比の比較に使ってください。線の形 (二次の効果、線幅の違い) までは再現しません。

#### 文献の図 (スクショ) を足すと、線の形が近づきます

ダイアログの「**文献の図 (スクショ) から線の形を合わせる**」を開いて、SI の図のスクショを貼り、
スペクトルの範囲をドラッグで囲み、**枠の左端と右端の ppm** を入れると、図から**信号ごとの線幅**を読み取ります。

- 位置・多重度・J・H 数は **SI の文が優先**です。図は線幅を測るためだけに使うので、**スクショが無くても使えます**
- 図が粗くて読めない信号 (山の幅が 3 画素より細い) は、下の「線幅」の値を使います
- 読めた本数は「図から線幅を読めた信号: 9 / 12」のように出ます

### 印刷する

ツールバーの「**印刷**」で、今の図と測定条件の表 (スペクトル名・核種・周波数・溶媒・積算・測定日・備考) を 1 枚に印刷します。
印刷画面から PDF で保存もできます。文献から作ったスペクトルは、備考に引用元が入ります。

### 図を大きく表示する

- ツールバーの左右の端にあるボタン (または `[` `]` キー) でパネルを閉じると、図が画面いっぱいに広がります。
- 画面下の `−` `100%` `＋` で表示倍率を変えられます。`%` の部分を押すと画面に合わせます。

### PowerPoint で編集する (SVG)

1. ツールバーの「SVG」で保存します。
2. PowerPoint の「挿入 → 画像 → このデバイス」で SVG を入れます。
3. 画像を右クリック →「図形に変換」。線・マーカー・文字がすべて PowerPoint の図形とテキストボックスになります。
   上付き・下付き (¹H, C₆D₆) も PowerPoint の書式として残ります。

### 推移グラフ (反応の経時変化)

1. 時間ごとの `.jdf` をまとめて読み込みます。時間は次の順で決まります。
   左の「時間」に入れた値 → 名前の数値 (`0 h`, `6 h`, `24 h` など) → 測定時刻 (最初の測定 = 0)
2. 範囲ツール (G) で、追跡したいピークをスペクトル上で左右にドラッグします。右の「推移グラフ」で名前とプロトン数 (nH) を入れます。
3. 「グラフを表示」で推移グラフに切り替わります。縦軸は次から選べます。
   - 合計を 100% (転化率・生成比)。内部標準を「合計から除く範囲」に指定できます
   - 基準の範囲との比 (内部標準)
   - 最初の時点を 100%
   - そのままの値
4. グラフもスペクトルと同じく、コピー・SVG・PNG で書き出せます。値の表は CSV で保存できます。

### スタイルのテンプレート

右の「スタイルのテンプレート」で、今の見た目 (文字の大きさ・フォント・線の色・表示の設定、必要なら表示範囲) を名前を付けて保存できます。
★の既定のテンプレートは、新しく `.jdf` を開いたときに自動で当たります。ファイルに書き出して研究室で共有できます。

### ショートカット

| キー | 動作 |
|---|---|
| V / Z / H | 選択 / 範囲を拡大 / 高さ |
| P / I / M | ピーク値 / 積分 / マーカー |
| O / R / A / L / T | 楕円 / 四角 / 矢印 / 線 / テキスト |
| G / B | 推移グラフの範囲 / 基準合わせ (溶媒ピークをクリック) |
| F / 0 | 縦を自動調整 / 全体表示 |
| ホイール / Shift+ホイール | 横 / 縦の拡大縮小 |
| `+` / `-` | 画面の表示倍率 |
| `[` / `]` | 左 / 右のパネルを開く・閉じる |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+C / Ctrl+V / Ctrl+D | 図形のコピー / 貼り付け / 複製 |
| Ctrl+Shift+C | 図をコピー (Word / PowerPoint 用) |
| Ctrl+S / Ctrl+Shift+S / Ctrl+O | 保存 / 名前を付けて保存 / 開く |
| 矢印キー (Shift で10倍) | 選択中の図形を少し動かす |

文字は `^{..}` で上付き、`_{..}` で下付き、`*{..}` で斜体、`**{..}` で太字になります (例: `H_{2}O`, `^{1}H NMR`, `*{J. Am. Chem. Soc.}`)。

## 設定

「設定」から次のものを変更できます。設定はブラウザに保存されます。

- 研究室の基準値 (初期値: C₆D₆ の ¹H = 7.15 ppm。ほかは Fulmer et al. の値)
- 不純物照合の許容幅
- 自作の不純物 (¹⁹F・³¹P や研究室でよく見る化合物)
- PNG の解像度 (PNG で保存するときと、ベクターのコピーに対応していないブラウザでコピーするとき)

## 開発

```bash
npm test          # 単体テスト (samples/*.jdf があれば実データでも確認)
npm run typecheck
npm run build     # dist/ に静的ファイルを出力
```

- 測定データ (`samples/`, `*.jdf`, `*.nmrfig`) は `.gitignore` でリポジトリから除外しています。
- 開発中はコンソールの `__nmr.load('/samples/xxx.jdf')` で読み込み、`__nmr.snapshot('name')` で図を `.dev-output/` に保存できます。
  `__nmr.libraryFrom(['/samples/a.jdf', ...])` でホーム画面を試せます (フォルダを選ばずに一覧を作る)。
- `scripts/ppt-svg-check.ps1 -Svg <file>` で、SVG を PowerPoint に入れて「図形に変換」した結果 (テキストの大きさ・上付き下付き) を確認できます。
  最小化した新しいプレゼンテーションだけを使い、開いているファイルには触れません。
